## 1. 範囲と要求の根拠

本計画の対象は、[02_development_step.md](../02_development_step.md) の **Stage 2：マルチプロセス（無菌調査・権限減衰）と決定論的メモリ管理（Step 2-1・Step 2-2・Step 2-3）** 全体、および Stage 1 完了版（`Stage 1 REQ-01`〜`Stage 1 REQ-11`、Zed ACP サーバー実動確認済み）の非回帰維持である。
- 本計画の要求 ID は本計画内で一意に **`REQ-01` 〜 `REQ-10`** として採番する（先行 Stage 1 の要求を参照する場合は必ず `Stage 1 REQ-XX` と明記して区別する）。
- **確定状態（版 `r1`）**: 初版で抽出した利用者判断事項（`B-01`〜`B-03`）、内部設計細部のおまかせ合意（`OM-201` 含む）、および検証精査（`PT-03`: `MF-T01`〜`MF-T04`, `SG-T01`）はすべて確定・反映済みであり、**未解決の判断待ち（分類 B）および要求曖昧さ（分類 A）は 0 件** である。

## 4. 非機能要求・制約・互換性および検証範囲

### 4.1 適用される非機能要求・アーキテクチャ制約・互換性
1. **Ring 0 カーネル純粋性と単一所有境界**: `packages/agent_kernel` は外部通信・FFI・UI 依存を持たない純粋 Dart パッケージのまま維持し、マルチ `Isolate` 実行時も `JjDriver` 更新直列化・監査ログ追記・クオータ事前予約加減算・ACP 承認ゲートが競合破壊を起こさない単一調停構造とする。
2. **Zed ACP v1 プロトコル互換性**: Stage 1 で確立した ACP v1 Extensibility 規約（標準オブジェクト直下に未知キーを置かず固有統計等は `_meta["fm_agent_os/..."]` に格納）および `stdout` 100% NDJSON 純度を厳守する。
3. **秘密情報の絶対非露出と本番 SSRF バイパス禁止**:
   - `OPENROUTER_API_KEY`、`OLLAMA_API_KEY` 等の秘密情報の実値は、ソースコード・コミット物・監査ログ（`syscalls.jsonl` / `llm_io.jsonl`）・標準出力/エラー・子プロセス環境変数・計画/証跡文書のいずれにも一切露出させず `SecretRedactor` で `<REDACTED>` マスクする。
   - 本番 `agent_os_daemon.exe` の公開 CLI 引数および環境変数には、SSRF 遮断を緩和・無効化するバイパス設定を一切設けない。
4. **AOT 単一バイナリ互換性**: 追加する外部パッケージ（例: HTML 解析用の pure-Dart `package:html` 等）はすべて Build Hooks / `dart:mirrors` 非依存とし、`dart compile exe` による単一 `.exe` 生成を維持する。
5. **anti-bot / CAPTCHA 回避の禁止**: `sys_web_search` / `sys_web_fetch` において、CAPTCHA・Cloudflare Turnstile 等の anti-bot チャレンジを自動突破・迂回する処理は一切実装しない（遭遇時は構造化エラーとして返す）。
6. **合意にない性能 SLO・数値品質目標の新設禁止**: 応答レイテンシ秒数目標やコードカバレッジ率目標などの追加要求は利用者から提示されていないため、根拠のない数値目標は新設しない（コンテキスト上限内に収めるページング、クオータ上限での `EDQUOT` 停止、I/O・受信サイズ上限は機能要求として検証する）。

- **今回実施する確認（Build / Analyze / Unit / Integration / E2E 実機観測）**:
  - **静的解析・AOT ビルド（`E1`）**: `mise exec -- dart analyze`（全パッケージ警告・エラー 0 件）および `dart compile exe` による `agent_os_daemon.exe` / `acp_cli_client.exe` ビルド成功（`REQ-10`）。
